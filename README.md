# 基于Unitree Go2 EDU四足机器人室内巡检方案建模与演示设计
## 项目简介
本项目以宇树Unitree Go2 EDU教育版四足机器人为开发平台，面向实验室/走廊室内巡检场景完成整套方案设计。
项目在暂无实体机器人硬件、无法开展实体测试的条件下，完成机器人简化三维建模、室内巡检场景搭建、巡检任务流程规划、软硬件系统方案设计，产出一套面向大学生机器人竞赛的完整方案雏形，可对接全国大学生机器人大赛、RoboMaster机甲大师人工智能挑战赛相关赛道。

**关键词**
Unitree Go2 EDU, 四足机器人, 室内巡检, 三维建模, 任务流程设计, 路径规划, 机器人方案设计, 传感器标注

## 1 机器人平台基础介绍
Unitree Go2 EDU是宇树科技面向教育、科研领域推出的四足机器人开发平台：
- 运动系统：四足关节驱动结构，具备行走、转向、低速越障能力，可适应室内门槛、线缆等轮式机器人难以通行的环境；
- 感知硬件：机载激光雷达、深度视觉相机、IMU惯性测量单元；
- 开发接口：开放官方SDK、ROS驱动、URDF模型文件，支持二次开发、自主导航、视觉目标识别。

## 2 总体方案设计
### 2.1 应用巡检场景
场景设定：高校实验室+连通走廊联合巡检场景
巡检目标：实验室设备状态巡查、通道障碍物检测、异常区域标记记录。

### 2.2 巡检路线规划
完整路线：起点待命区 → 巡检点1（机柜区域） → 巡检点2（实验操作台） → 巡检点3（走廊拐角） → 动态障碍避让区域 → 返回终点待命区
每个巡检点位执行定点图像采集、环境信息记录任务。

### 2.3 机载传感器与功能说明
1. 激光雷达：室内环境SLAM建图、全局定位、远距离障碍物探测
2. 深度视觉相机：近距离障碍感知、设备视觉巡检、目标图像采集
3. IMU惯性单元：机器人姿态解算、辅助里程计定位
4. 机载计算单元：导航算法运算、视觉AI推理
5. 无线通信模块：远程指令接收、巡检数据回传
6. 腿部伺服电机：实现四足步态行走、转向、小幅越障

## 3 机器人简化三维建模方案
本项目采用轻量化简化建模思路，剔除细小零件，聚焦机器人功能结构：
1. 建模主体：机器人躯干机身、四条机械腿、头部感知安装支架；去除螺丝、外壳装饰纹路等非必要微小结构；
2. 三种实现途径任选其一：
   - 方案A：使用Blender / SolidWorks / Fusion360自主绘制简化三维模型；
   - 方案B：基于宇树官方开源URDF/mesh网格模型进行轻量化二次整理；
   - 方案C（无三维软件备选，课题允许）：绘制二维结构示意图替代三维模型；
3. 建模配套输出成果：机器人外形结构图 + 传感器位置标注图，清晰标识各类感知硬件安装位置。

## 4 软件功能模块说明
整套控制系统分为五大核心功能模块：
1. **环境感知模块**
接收激光雷达、深度相机、IMU原始数据，完成多传感器数据融合，识别环境障碍物与巡检目标；
2. **定位建图模块**
依托多传感器融合SLAM技术，构建室内二维环境地图，实时解算机器人自身坐标位置；
3. **路径规划模块**
全局路径规划：按照预设顺序遍历全部巡检点位；
局部动态规划：检测到前方障碍物时，实时生成绕行轨迹；
4. **四足运动控制模块**
接收上层轨迹指令，规划稳定四足步态，控制机器人完成行走、转向、启停、小幅越障；
5. **巡检任务模块**
到达指定巡检点位自动触发图像采集，存储环境巡检信息，向上位机上传巡检日志。

## 5 巡检完整任务流程
1. **任务初始化**
机器人在起点待命区上电，加载预构建室内地图，建立与上位机无线通信。
2. **自主巡航行进**
按照预设全局巡检路线，依次前往各个预设巡检点位。
3. **定点巡检作业**
抵达巡检点位，自动调整姿态，启动视觉采集，记录现场图像与环境数据。
4. **障碍物检测与绕行**
行进途中持续扫描环境，若感知障碍物，启动局部路径重规划，主动避让障碍。
5. **任务返航闭环**
全部巡检点完成作业后，自主规划返航路线返回起点；上传全部巡检记录，本次巡检任务结束。

## 6 关键技术说明
1. **多传感器融合SLAM**：激光雷达与深度视觉融合，弥补单一传感器缺陷，实现室内高精度定位与环境地图构建；
2. **双层路径规划架构**：全局路径保障巡检点位有序遍历，局部动态规划应对走廊临时障碍物，保障巡检连续执行；
3. **四足机器人步态运动控制**：相比轮式巡检机器人，具备跨过门槛、地面线缆的越障能力，适配实验室复杂地面环境；
4. **机载视觉目标检测**：在巡检点位利用视觉传感器识别设备外观异常、通道堆放障碍物，实现自动化巡检观测。
